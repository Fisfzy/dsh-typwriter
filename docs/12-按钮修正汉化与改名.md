# 第八轮：× 按钮逻辑修正 + 按钮回归 + 汉化补全 + 品牌改名 Typwriter

日期：2026-11-08

## 一、× 按钮与其它按钮重合（已修）

### 你要求的行为
> 有文件的时候不显示关闭键，把所有文件都关完了再显示。

### 改法
`EditorGroups.svelte` 的条件从「多窗格就显示」改为：

```svelte
closable={editorGroups.grid.length > 1 && editorGroups.tabsOf(g.id).length === 0}
```

即：**多窗格 且 该窗格没有标签**时才显示 ×。

### 实测（四宫格，4 个窗格）
| 窗格 | 标签数 | 有 × |
|---|---|---|
| 0 | 2 | ❌ |
| 1 | 1 | ❌ |
| 2 | 1 | ❌ |
| 3（关掉它的标签后） | **0** | ✅ |

点掉那个 × → 4 格变 3 格，× 随之消失，文档仍是 `main.typ`。
**因为只出现在空窗格上，而空窗格没有标签栏按钮，所以不再和眼睛/分屏按钮重叠。**

## 二、偏好设置跑回文件菜单、返回 DSH 消失（已修）

### 原因
这两处上一轮我用 `{#if embedded}`（`window.self !== window.top`）门控。你直接打开
`http://127.0.0.1:4400/typwriter/` 时它是**顶层窗口**，`embedded === false` →
两个按钮都被隐藏，于是「偏好设置」只剩文件菜单里那一条。

### 改法
去掉 `embedded` 门控，**两个按钮始终显示**：
- 左侧：`偏好设置`（点了直接开设置面板）
- 右侧：`返回 DSH`（在宿主里 `postMessage` 生效；顶层打开时是空操作，不会报错）

实测标题栏顺序：
```
偏好设置   文件  编辑  视图  插入  格式  拼写检查  终端  帮助   布局   返回 DSH
```

> 顺带修了一个我上一轮留下的构建错误：删 `{#if embedded}` 时漏删对应的 `{/if}`，
> 导致 `Unexpected block closing tag`、构建失败。已修正。

## 四、品牌改名 Texpile → Typwriter

### 改了什么
| 位置 | 改动 |
|---|---|
| `messages/*.json`（en / zh-Hans / zh-Hant / de / pt-BR） | 消息值里的 `Texpile` → `Typwriter`，**每个语言 49 条** |
| `index.html` | `<title>Texpile</title>` → `Typwriter` |
| `views/StartView.svelte` | `<title>` 与 logo `alt` |
| `views/workspace/WorkspaceView.svelte` | 窗口标题模板 `${folder} - Texpile` → `- Typwriter` |
| `modals/window/PreferencesDialog.svelte` | `aria-label="Texpile"` → `Typwriter` |

实测：窗口标题 = **`main.typ - 毕业论文初稿 - Typwriter`**

### 刻意**没有**改的（改了会坏）
| 标识符 | 原因 |
|---|---|
| `.texpile/` 目录、`.texpile/config.json`、`comments.jsonl` | 磁盘格式，改了等于让所有已有工程的配置失效 |
| `window.texpileNative` / `texpileTypst` / `texpileTerminal` / `texpileAcp` … | 桥接全局名，改名要同时改 shim 与整个应用源码，风险高、收益低（用户看不见） |
| `texpile:` 前缀的 localStorage 键 | 同上，且改了会丢用户的本地设置 |
| `logo` 图片资产（`branding/Logo-*.svg`） | 二进制/矢量资产**没法文本替换**——界面左上角那个 wordmark 仍然显示 Texpile |

> 如果你要连 wordmark 一起换，需要提供 `Typwriter` 的 logo（SVG），我可以直接替换资产。
