# 第四轮：修卡死 + 返回 DSH + 三栏布局 + 预览栏代理按钮

日期：2026-11-08

## 一、代理面板一直转圈（已修）

### 根因：并发 `start()`
面板挂载时会调用两次 `texpileAcp.start()`。而 `AcpHost.start()` 开头无条件 `close()` 上一个子进程，
于是**第二次调用把第一次刚开始的 dsh 进程杀掉了**，第一次的 `initialize` 永远等不到回应 →
Promise 永不 resolve → 面板停在「正在启动 DeepSeek Harness…」。

日志证据：一次点击出现**两条** `[typwriter:acp] non-protocol stdout: [dsh-model-follow] …`，即起了两个进程。

### 修法
1. `start()` 变并发安全：`this.starting` 复用；已有活会话直接返回 `{ok:true}` 不重启进程。
2. `#request` 加超时（默认 30s），把"永不回应"变成明确报错而不是无限转圈；
   `session/prompt` 显式传 `0` 关掉超时（一轮对话可能很久）。
3. 新子进程加 `this.closing = false`，避免上一轮 `close()` 的标记误判新进程退出。

验证：点「布局 › 代理对话」后面板稳定进入
```
终端  问题  批注  代理
DeepSeek Harness
让 DeepSeek Harness 处理这个项目。
```
不再有「正在启动」。

## 二、左上角「返回 DSH」按钮（已完成）

`lib/chrome/WorkspaceMenuBar.svelte`：菜单栏最左侧加一个按钮，`文件/编辑/…` 整体右移。
实测（iframe 内）标题栏读作：

```
返回 DSH   文件  编辑  视图  插入  格式  拼写检查  终端  帮助   布局   chapter02-theory.typ …
```

- 只在 `iframe` 里显示（`window.self !== window.top`），直接开 `/typwriter/` 时不出现——避免在非宿主环境里出现无效按钮。
- 点击后 `window.parent.postMessage({type:'typwriter:back'})`。
- 插件浏览器半片（`dist/client.js`）监听该消息，惰性取 `ctx.get('layout').selectPanel(null)` 切回主对话；
  用惰性 `get` 而不是 `inject`，避免服务名不匹配导致**整个插件不激活**。

## 三、预览工具栏「代理」按钮（已完成，但形态与你要的不同）

在 `TypstPreview.svelte` 的工具栏加了一组 `agent`（`Bot` 图标，`aria-label="代理对话"`），
放在 zoom 组右侧。实测预览工具栏里已出现 `代理对话` 按钮。

**但它是打开底部 dock 的 Agent 页，不是"右侧新窗口"。** 这一点我需要说清楚：

Texpile 的右侧窗格不是可插拔的——`pdfPaneOpen` / `pdfPopout` 是写死在 `paneLayout` 与网格里的。
要做出真正的「右侧独立代理窗口」，需要：
1. 在 `paneLayout.svelte.ts` 新增一个 `agentPaneOpen` 的窗格位，并改 `WorkspaceMain` 的网格模板；
2. 把 `AgentPanel` 从「底部 dock 的子视图」提升为「可独立挂载的面板」（现在它依赖 dock 的 `view` 状态）；
3. 如果还要"独立窗口"，得走 `childWindows` 那套注册表，新增一种窗口类型。

这是本轮唯一没按你原话实现的一项，估计 1~1.5 天。当前按钮已经可用（指向 dock），可以先用着。

## 四、布局 › 编辑器：横向三栏（已完成）

实测 `布局` 菜单的布局按钮从 4 个变 5 个：

```
单个编辑器   左右两个   横向三栏   上下两个   四宫格
```

点「横向三栏」后编辑器网格实测为 `grid-template-columns: 360px 1px 360px 1px 360px`
（三列 + 两条 1px 分隔线；360px 是 `MIN_COLUMN_PX` 下限，窗口更宽时会按比例放大）。

### 改了 3 处
| 文件 | 改动 |
|---|---|
| `lib/workspace/groups/layouts.ts` | `EditorLayout` 加 `'columns3'`；`LAYOUTS` 加一项；`CELLS.columns3 = [[0,0],[0,1],[0,2]]`；`previewViewOf` 让三栏像两栏一样按列同步 |
| `lib/workspace/groups/groupSizes.ts` | `sizes()` 泛化：两栏仍按用户拖动比例，三栏及以上等分（**分栏拖拽暂时只支持两栏**） |
| `views/workspace/titlebar/LayoutMenu.svelte` | 布局按钮数组加 `{ layout: 'columns3', icon: Columns3, label: () => '横向三栏' }` |
